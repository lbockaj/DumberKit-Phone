# Changelog

## [1.0.0] - 2026-10-11
First public release, based on Fossify Phone 1.11.1.

### Added
- Call history, contacts and favorites as tabs switched with ← / →, the app starts on the call history with the
  newest call selected; the last calls show up right away at start
- Contact lists like DumberKit: Contacts: top bar with jump to letter (Ab, `*`), search, dialpad and menu, OK opens the contact
  in DumberKit Contacts, holding OK shows the contact's actions
- A digit anywhere starts dialing; the green key calls the selected call or contact, `#` sends an SMS
- Dialing for keys: the number in a big field with a handset and a blinking cursor, contacts matching it (number or T9 name) below, Back deletes, hold 0
  for +, hold 2–9 for speed dial
- Incoming call screen: the caller's photo (only a real contact photo), Call / OK / ← answer, → declines, Back silences the ringing and a second
  Back hides the screen
- Call screen with a row of round buttons for ← / → (the arrows ↑ / ↓ set the volume during calls on keypad phones):
  speaker, mute, hold, add call, hang up; the digits send tones
- The screen turns off 2 s after a call starts (an incoming one once answered) and with the green key (device admin, asked once), so the ear
  can't touch anything – only on phones without a proximity sensor, a real sensor does it by itself; otherwise it dims after 10 s
- Settings made for keys, with *Allow touch input* and *Turn the screen off during calls*, and an About screen with
  all the keys
- Dialpad sounds off by default; a dialpad button in the top bar
- Fast start: the last calls are shown at once, the app opens straight on the call history
- Smaller app: Commons screens the app never opens are left out, only the 50+ languages with a real translation
  are offered
- App icon with an old push-button phone, green by default; other colors from the settings switch the launcher icon
